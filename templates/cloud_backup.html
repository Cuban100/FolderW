Cloud Backup

Mirrors your entire backup destination (Full Backup + every Snapshot) to a cloud remote right after every successful local backup — scheduled, watchdog, or manual. Uses rclone, so any provider rclone supports works (Google Drive, Amazon, Dropbox, Backblaze, and 40+ others) — configure a remote with rclone config first; FolderW never handles cloud credentials itself.

{% if backup_method == 'incremental' %}
Expect cloud storage usage to be much higher than your local Destination Used. Incremental snapshots share unchanged files as hardlinks on disk, so they cost almost no extra local space — but hardlinks aren't a concept cloud storage (or rclone syncing to one) understands, so each snapshot uploads as a full, independent copy. Confirmed directly: a 160 MB local destination (deduplicated) became 3.6 GB once synced — roughly 23× larger. Plan your remote's storage quota (and Snapshots to Keep setting) with this in mind.
