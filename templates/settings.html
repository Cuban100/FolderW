Changing these starts a new full backup

These identify which backup this is. Changing any of them means FolderW is now pointed at a different backup, so the old one's history is cleared and a fresh full backup runs from scratch.

Specify the path of the folder or device you want to back up. Example: /home/user/Documents
Specify the directory where the backups will be stored. Ensure there is enough space for the backup.
Name of the folder created inside the Base Backup Directory to hold "Full Backup" and "Snapshots". Example: Documents
Specify the name and location of the SQLite database file that will store configuration settings and backup records.
Incremental: each snapshot is a complete, independently restorable copy, only storing what changed since the last snapshot — stays small indefinitely. Differential: each snapshot stores only the files changed since the original full backup, growing larger over time — restoring a point in time needs the full backup plus that snapshot together. Switching between the two starts a new full backup, so snapshots never end up mixing both shapes in the same Snapshots folder.
